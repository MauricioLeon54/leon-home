# LEÓN visual identity

LEÓN Home uses the original lion symbol and geometric LEÓN wordmark. Preserve their shapes,
proportions and accent. Use “LEÓN Home” for the product name and “LEÓN” for the brand.

## Palette

| Role                  | Color     |
| --------------------- | --------- |
| Background            | `#0e0e0e` |
| Primary text and logo | `#eeeae3` |
| Secondary text        | `#aaa89f` |
| Quiet borders         | `#34332f` |

Keep the presentation restrained: one clear brand moment, generous spacing and useful labels.
Use sentence case for interface copy and English for documentation, installation prompts,
release notes and public product text. Names, commands, URLs and persisted identifiers keep
their required spelling; the accented LEÓN brand name stays unchanged.

## README artwork

`assets/readme-header.svg` is the editable source. It embeds the existing PNG brand marks and
uses system fonts without remote resources. `assets/readme-header.png` is the rendered GitHub
image, so the header has a consistent background in both light and dark reader themes.

Keep the PNG and SVG aligned when changing the artwork. Add meaningful alternative text to
images, keep navigation as real README links and verify readability on a phone. Brand assets
remain the owner's property; making source public does not grant a separate brand license.
