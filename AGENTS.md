# LEÓN Home

Read the user coding standards when available. Preserve strict types, bounded I/O, explicit owner authorization, pinned release signatures and per-home configuration. Never publish credentials or site state. Use pnpm scripts, Ruff, TypeScript and Cargo checks; do not compile on a deployed Pi. Public application updates cannot replace root broker configuration. See sharing/guides for installation and maintenance.

Use English for public documentation, setup prompts and release notes. The phone UI is English and Spanish: write visible texts through `t()` and add the Spanish to `web/src/i18n/es.ts`. Preserve the accented LEÓN brand name, protocol keys and existing per-household identifiers. Follow docs/BRAND.md for README artwork and visual identity.
